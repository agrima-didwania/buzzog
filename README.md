# Buzz Originals — The Buzz Never Sleeps ⚡

Raw, unfiltered entertainment coverage of Indian reality TV (Bigg Boss, Splitsvilla, Khatron Ke Khiladi) and Bollywood gossip — built for the group chat.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Turbopack)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) & Custom Design Tokens
- **Typography**: [Google Fonts](https://fonts.google.com/) (`Anton`, `Space Mono`, `Plus Jakarta Sans`) via `next/font/google`
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## Features

- 🔴 **Live Breaking News Ticker**: Smooth infinite scrolling headlines with LIVE indicator
- 📰 **Breaking Hero & Ranked Trends**: Top stories with custom ranking badges and reaction counters
- 🏷️ **Dynamic Category Strip**: Filter by Bigg Boss, Splitsvilla, KKK, Bollywood Gossip, Web Series, and Videos
- 🗳️ **Interactive Poll Card**: Real-time voting mechanism with percentage transitions and voter feedback
- 📊 **The Buzz-O-Meter**: Dynamic contestant drama popularity ranking
- 💌 **Buzz Squad Newsletter**: Interactive email capture with confirmation feedback
- 📱 **Fully Responsive**: Mobile-first design with drawer navigation and reduced-motion support

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
npm start
```
